# Haier MatrixTV BE Scenes theme

This copies the upstream [Scenes theme](../../themes/scenes) wallpapers and adds the configuration used on one Haier MatrixTV BE. It rotates the wallpaper hourly, enables the frosted glass dock, sets four dock apps, maps the TV button to Live TV, and maps the physical Settings gear to the quick settings panel. The three-line button is deliberately unmapped because it shares Android scan 240 with the gear. The wallpaper assets remain from the MIT-licensed CleanYourTV project; see the repository [LICENSE](../../LICENSE).

The dock app packages are Netflix, Prime Video, YouTube, and Spotify in that order. The launcher must be built with the on-screen Settings chip fix in this repository for that chip to open the same quick panel. The physical gear shortcut comes from this theme's `app_keys` setting.
