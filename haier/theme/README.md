# Haier MatrixTV BE Scenes theme

This copies the upstream [Scenes theme](../../themes/scenes) wallpapers and adds the configuration used on one Haier MatrixTV BE. It rotates the wallpaper hourly, enables the frosted glass dock, fills six dock slots with Netflix, Prime Video, YouTube, Spotify, ARY Plus, and BrowseHere, maps the TV button to Live TV, and maps the physical Settings gear to the quick settings panel. The three-line button is deliberately unmapped because it shares Android scan 240 with the gear. The wallpaper assets remain from the MIT-licensed CleanYourTV project; see the repository [LICENSE](../../LICENSE).

Four dock apps are pinned in that order; installed apps fill the two remaining slots. The theme groups all 14 scenes into daytime, sunset, and night sets, using the configured sunrise and sunset. Without coordinates, the launcher uses fixed daytime hours. A 45% sky overlay changes gradually through the day. The launcher must be built with the on-screen Settings chip fix in this repository for that chip to open the same quick panel. The physical gear shortcut comes from this theme's `app_keys` setting.

The Home header can show current weather in Celsius: temperature, conditions, feels-like temperature, and humidity. Set `weather_city`, `latitude`, and `longitude` in `launcher/app/src/main/res/values/config.xml` locally before building. These values are blank in the public repository to keep the owner's location private; the weather line stays hidden until all three are set. While Home is visible, it refreshes from [Open-Meteo](https://open-meteo.com/) every 30 minutes and keeps the last result if the TV is offline. The quick panel's top offset is 132dp to sit below the Settings chip after the weather line was added.
